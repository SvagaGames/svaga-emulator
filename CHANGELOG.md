## 1.0
- В «О приложении» указана текущая версия (раньше там оставалась 0.7.0).
- Svaga Emulator 1.0: новая нумерация версий, отсчёт начинается с 1.0.
- В версию вошло всё из 0.8.0: игры сами привязываются к каталогу Svaga, наигранное время идёт в Svaga Archive.

## 0.8.0
- Игры сами привязываются к каталогу Svaga по названию, и наигранное время засчитывается в Svaga Archive: часы, уровни и достижения.
- В карточке непривязанной игры появилась подсказка.

## 0.7.0

- Новая иконка: геймпад с лисьими ушками Svaga.
- Обновление прямо из эмулятора: проверка новой версии, загрузка и установка поверх.

## 0.6.0

- «Войти через Svaga Archive»: вход без пароля, если вы вошли в Archive через Google, Яндекс или VK.
- Полка «Доступно в Svaga»: игры, которые Создатель выложил для скачивания, ставятся в одно касание.
- Если игру открыли из Archive и для неё есть файл, появляется кнопка «Скачать игру».

## 0.5.0

- Новый дизайн в стиле Svaga Archive: полка с обложками, «Продолжить», поиск, фильтр по системам.
- Обложки: из каталога Svaga для привязанных игр, иначе из libretro-thumbnails по имени ROM-файла.
- Вкладки «Игры», «Системы» (ядра, BIOS), «Игроки», «Профиль» (Svaga ID, статистика).
- Карточка игры: оценка сообщества, рейтинг игроков, привязка к Svaga, смена системы.
- Сборка на GitHub с 30+ ядрами libretro и постоянной ссылкой на APK.
